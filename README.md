# AURA (Accenture Universal Reliability Assistant) | CAPSTONE PROJECT 2025

## 💎 Deskripsi Proyek

**AURA (Accenture Universal Reliability Assistant)** adalah sebuah platform _Predictive Maintenance Copilot_ yang dikembangkan untuk merevolusi cara industri memantau dan memelihara aset vital mereka. Proyek ini hadir sebagai solusi atas permasalahan tingginya biaya _downtime_ mesin yang tidak terduga dan kompleksitas data sensor yang sulit dianalisis secara manual oleh operator.

Dirancang untuk teknisi lapangan dan manajer operasional, AURA menggabungkan kekuatan _Predictive Analytics_ untuk menghitung _Remaining Useful Life (RUL)_ mesin dengan kecerdasan _Generative AI_. Sistem ini memungkinkan pengguna berinteraksi dengan data mesin melalui percakapan alami (chat), mendapatkan wawasan penyebab kerusakan, dan menerima rekomendasi perbaikan secara otomatis. AURA dikembangkan oleh tim Capstone Project sebagai upaya modernisasi sistem pemeliharaan industri menuju Era Industry 4.0.

## 🚀 Fitur Utama

- **Smart Dashboard:** Visualisasi _real-time_ data sensor (suhu, getaran, tekanan) dengan indikator kesehatan aset yang intuitif.
- **AURA Copilot Chat:** Fitur asisten cerdas di mana operator dapat bertanya "Kenapa suhu pompa naik?" dan mendapatkan jawaban berbasis data historis dan teknis.
- **Predictive Alerts:** Notifikasi dini mengenai potensi kerusakan mesin sebelum terjadi, lengkap dengan estimasi waktu kegagalan.
- **Asset Management:** Fitur untuk mendaftarkan, mengubah, dan menghapus data aset mesin serta konfigurasi sensor IoT.
- **Automated Reporting:** Pembuatan laporan insiden dan log pemeliharaan secara otomatis.

### 🧩 Back-End

| Teknologi / Library | Fungsi                                                                                    |
| :------------------ | :---------------------------------------------------------------------------------------- |
